# 项目简介

## 核心功能
- 基于YOLOv8的快递纸箱缺陷检测，支持4类识别：正常纸箱、裂纹纸箱、开口纸箱、受潮纸箱
- 支持多种输入源：单张图片、图片文件夹、视频文件、本地摄像头
- 提供实时检测界面，显示目标位置、目标总数和置信度信息
- 支持批量检测功能，可直接查看所有检测结果
- 支持检测结果保存功能
- 提供自定义设置：置信度阈值、IOU阈值、显示标签和原图选择
- 包含完整程序文件、UI界面源文件、数据集图片和运行教程

## 适用场景
- 快递物流行业中的纸箱质量检测
- 生产线自动化缺陷检测
- 仓储物流质量控制系统
- 物流包装完整性检查

## 技术特点
- 技术栈：Python 3.9 + OpenCV-Python + PyQt5 + Ultralytics + PyTorch 1.9
- 内置3300张标注数据集，包含4类纸箱缺陷样本
- 提供完整源码、训练好的模型、数据集和详细教程
- 支持Pycharm+Anaconda或VSCode+Anaconda开发环境
- 提供图形化用户界面，操作简便直观
